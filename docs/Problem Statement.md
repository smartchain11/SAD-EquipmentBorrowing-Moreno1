# Problem Statement

The College maintains laboratory equipment—laptops, projectors, routers,
cameras, microphones, extension cords, and other ICT devices—that students,
faculty, and staff borrow. Borrowing is currently recorded manually, so it is
difficult to know which items are borrowed, who borrowed them, when they are
due, which items are available, and which transactions are overdue. Lost,
delayed, or undocumented returns waste time and resources.

To solve this, the College needs an Online Equipment Borrowing and Return
Monitoring System. The system records borrowing transactions in a centralized
database, keeps equipment availability up to date automatically, flags overdue
returns, and provides searchable, filterable records accessible from any
browser. (96 words)
