# Role-Permission Matrix

| Action | Administrator | Officer | Borrower |
|--------|---------------|---------|----------|
| **View Equipment** | Yes | Yes | Yes |
| **Add/Edit/Delete Equipment** | Yes | Yes | No |
| **Request to Borrow (Pending)** | Yes | Yes | Yes |
| **Cancel Own Request** | Yes | Yes | Yes |
| **Approve / Reject Requests** | Yes | Yes | No |
| **Claim Equipment (mark Borrowed)** | Yes | Yes | No |
| **Return Equipment** | Yes | Yes | No |
| **View All Transactions** | Yes | Yes | Yes (Restricted view could be applied) |
| **View Audit Logs** | Yes | No | No |
